              Voice mode

              Talk to Sunday out loud — full-duplex, with a live animated face. Tap the voice pill in the message bar to start (or the button below). It runs realtime, direct to the provider: OpenAI gpt-realtime today, Gemini Live next. Because it's the realtime API, it needs an OpenAI platform key — your ChatGPT/codex login doesn't cover it; add one under Brain → Advanced. Your mic streams to the provider only while voice mode is open; closing the overlay ends the session. Sunday's full brain + tools come along.

              Ambient observer

              Sunday listens to the mic in the background, figures out what you're doing right now, and shows it in the notch with how long you've been at it. Off by default; mic only. With local transcription installed, audio never leaves this Mac.

              Analytics for nerds

              Run Argus alongside Sunday — a local, zero-dependency observability dashboard for the agent itself: traces, tool calls, token usage, loops, and silent failures. It runs as its own process on 127.0.0.1:4317, stores everything in local SQLite, and sends nothing anywhere. Off by default. Each Sunday build bundles the latest Argus. Needs Node 22+ on your machine.
